# Nature–Machine Latent

探索自然声与机械声之间的可演奏声音空间，使用 RAVE 构建实时乐器与自动声景装置。

## 第一阶段

- 声音主题：气流与振动（风、树叶、虫鸣、风扇、电机、管道）。
- 初始实验：单声道、`v2_small`；具体参数在安装并验证 RAVE 后确定。
- 4070 台式机负责全部训练及试跑；5070 笔记本仅用于素材准备、试听、项目管理、演奏与装置调试，不进行任何训练。
- 首个界面目标：四个控制参数、冻结按钮、手动／自动平滑切换。

## 目录

| 目录 | 用途 |
| --- | --- |
| `docs/` | 项目计划、素材与设备管理说明 |
| `configs/` | 训练配置及版本说明 |
| `scripts/` | 后续添加素材检查、预处理、训练与导出脚本 |
| `datasets/manifests/` | 素材清单与训练／验证／测试划分 |
| `experiments/` | 实验设置、试听评价和模型索引 |
| `instrument/` | 实时演奏程序与控制映射 |
| `installation/` | 自动声景状态与控制程序 |

## 从这里开始

项目进展与重要决定见 [项目日志](docs/log.md)。

1. 阅读 [项目计划](docs/roadmap.md) 与 [素材管理](docs/data-management.md)。
2. 在仓库外建立声音数据目录，并进行独立备份。
3. 复制 `.env.example` 为 `.env`，填写本机路径。这只是约定，尚无程序自动加载它。
4. 将素材信息填入 `datasets/manifests/assets.csv`。
5. 开始训练前，复制 `experiments/TEMPLATE.md` 为新的实验记录。

当前处于素材准备阶段：已登记 S105 素材 566 个 WAV，建立 78 条优先试听候选，并完成清单与文件存在性校验。尚未完成试听、授权确认或数据划分，尚未安装 RAVE 或启动训练。详见 [S105 素材报告](docs/materials-s105.md)。

## 版本管理

代码、配置、素材清单和实验记录进入 Git；原始录音、预处理数据库、训练检查点和日志独立存储。
稳定版本保留在 `main`；较大的功能修改使用分支。实验用编号区分，不需要每次训练新建分支。
训练前记录代码提交编号、RAVE 版本、数据清单版本与实际命令。

上游：[RAVE](https://github.com/acids-ircam/RAVE)。本项目不包含或重新授权上游代码及第三方声音素材。
