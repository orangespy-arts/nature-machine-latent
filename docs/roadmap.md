# 项目计划

任务看板建议：待做 → 进行中 → 待试听 → 完成。
以下任务可在连接 GitHub 后转为 Issues。

## M1：素材准备

- [ ] 确定首批气流与振动素材范围。
- [ ] 建立仓库外的数据目录与独立备份。
- [ ] 登记来源、许可、录音条件与文件校验值。
- [ ] 检查音频可读取、削波、无效静音和重复素材。
- [ ] 按原始录音或录音场次划分训练、验证和测试集。
- [ ] 核对各类有效时长，并试听代表性片段。

完成标准：素材可读取、来源清楚、划分无同源泄漏。

## M2：第一个模型

本阶段所有训练和试跑均在 4070 台式机进行，5070 笔记本不承担训练。

- [ ] 在 4070 台式机建立独立训练环境，记录依赖版本。
- [ ] 验证 RAVE 版本及 v2_small 的实际配置。
- [ ] 创建 exp-001，保存数据清单与训练配置。
- [ ] 小规模试跑，记录显存与每步耗时。
- [ ] 验证检查点恢复训练。
- [ ] 完成试听、导出与加载验证。

完成标准：能训练、恢复、导出，并重现试听结果。

## M3：实时乐器

- [ ] 选择 Max/MSP 或 Pure Data。
- [ ] 探索潜在空间并记录可用区域。
- [ ] 建立四个控制参数与冻结按钮。
- [ ] 添加独立音量控制，测试切换时的音量与连续性。
- [ ] 在笔记本上记录声卡、缓冲设置、延迟和稳定性。

完成标准：控制可理解，声音稳定，无明显切换突跳。

## M4：自动声景装置

- [ ] 实现休眠、气流、振动、密集活动、衰退状态。
- [ ] 为各状态规定活动区域、变化速度与事件密度。
- [ ] 实现手动介入与平滑恢复自动运行。
- [ ] 进行长时间运行测试并记录问题。

完成标准：可自主运行，人工介入及退出自然，运行记录可追溯。
