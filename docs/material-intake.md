# 第一批素材整理

本流程原在 5070 笔记本完成；2026-11-12 起改在 Mac 上进行（见 [Mac 环境](environment-mac.md)），仅做素材管理与音频准备，不进行训练。Mac 上尚未安装 `convert_audio.py` 等脚本所需的 numpy、soundfile、soxr。

## 1. 登记原始文件

确认素材根目录后，先只读扫描：列出音频、文件大小、格式及校验值。
保留原始文件名和目录，不直接移动、重命名或覆盖原件。
同一校验值标记为完全重复，不自动删除；音频内容相同但编码不同的文件仍需进一步检查。
如原始素材目录不叫 raw，清单相对路径以该素材根目录为准，并在本机配置中记录根目录。

## 2. 核对音频属性

读取时长、采样率和声道数；无法读取的文件标记待检查。
文件扩展名不是可正常解码的证明，完整解码检查与属性读取分别记录。
先统计总时长和素材分布，再决定是否需要统一格式。

## 3. 人工试听与分类

使用 `datasets/manifests/assets.csv` 记录结果。
不要仅凭文件名推断来源、授权或声音类别；未知字段保留待确认。

| 字段 | 第一批建议 |
| --- | --- |
| category | nature / machine；混合或不明先留空，在 notes 说明 |
| sound_family | airflow / vibration / friction / impacts / other |
| description | 实际声源、强弱、变化、背景声及录音距离（已知时） |
| recording_group | 同一原始录音或录音场次使用相同编号 |
| source | 自录信息或具体来源链接 |
| license | 实际许可；未知填写 unknown |
| split | 整理阶段先用 unassigned |
| notes | 试听结论与问题，见下方约定 |

试听结论可在 notes 中写 `review=keep`、`review=hold` 或 `review=exclude`，并附原因。
重点听：声源是否清楚、是否削波、是否有无关讲话或音乐、是否长时间无有效声音，以及纹理变化是否符合项目方向。
噪声可能是目标素材，不因“有噪声”自动排除。exclude 仅表示暂不纳入数据集，不删除原文件。

## 4. 整理后再做处理与划分

- 原件保持不变，剪辑或格式转换输出到 processed 中的新版本目录。
- 衍生片段记录原始素材编号、起止时间及处理方式。
- 同场次录音及其片段保持在同一数据划分中。
- 未确认素材规模前，不预先固定训练／验证／测试的比例。
- 将素材、清单和处理记录一起交给 4070 台式机；只有清单不能重建原始音频。

## 第一批完成标准

- [ ] 确认素材根目录与备份位置。
- [ ] 完成文件清点、校验值与属性登记。
- [ ] 标记完全重复、解码问题和需人工确认的文件。
- [ ] 完成第一轮试听，记录分类、来源与许可。
- [ ] 汇总可用时长与类别分布，确定需补充的声音。

首批素材已完成只读清点，见 [S105 素材报告](materials-s105.md)；尚未试听或处理原始音频。
